它怎么工作

不猜、不打扰，只在真的该休息时打断你

很多护眼工具只会机械倒计时。护眼管家看的是「你到底在不在」，起身接水、开会走开，计时会自动归零。

1

每秒一次，本机判断

前置摄像头以低分辨率做一次人脸检测，只回答「有没有人」。画面在内存里用完即丢，不写盘、不上传。

2

到点接管屏幕

连续注视到达阈值（默认 30 分钟），全屏休息页覆盖一切，倒计时走完前无法误触关闭。

3

绿植 + 一句话

航拍森林与近景绿植两段实拍视频随机播放，配神经语音：「休息一下，离开屏幕，看看远处」。

六个平台

同一套逻辑，在你每块屏幕上

桌面三端开箱即用；安卓有编译好的签名安装包，扫码即装；iOS / iPadOS 需要用 Xcode 编译。全部源码都在仓库里。

Windows

即装即用

双击安装脚本选语言即可，注册表自启，托盘常驻，无窗口。

platforms/windows/安装到本机.bat

macOS

即装即用

LaunchAgent 开机自启，菜单栏图标，AVFoundation 取摄像头。

platforms/macos/install.sh

Linux

即装即用

XDG autostart，V4L2 取摄像头，Tk 兜底全屏休息页。

platforms/linux/install.sh

Android

扫码即装

Kotlin + CameraX + ML Kit 离线人脸，前台服务常驻，开机自启，全屏休息页。安装包已编译好，扫码直接装。

到「下载安装」区获取 EyeGuard-1.0.apk

iOS

需 Xcode

SwiftUI + Vision 人脸，前台可用摄像头；后台改为本地通知（系统限制）。

xcodegen generate && open EyeGuard.xcodeproj

iPadOS

需 Xcode

独立 bundle，只面向 iPad，版心加宽到 820pt，横竖屏都适配。

platforms/ipados/project.yml
隐私

摄像头在你手里，数据不出这台机器

这不是一句宣传语，是代码里能做到的事实：没有网络请求、没有统计 SDK、没有云端识别。

画面不留存

检测在内存中完成，一帧用完即丢。不截图、不录像、不写日志。

零网络请求

运行时不需要联网；人脸模型随安装包提供，语音是预生成好的音频文件。

拒绝授权也能用

不给摄像头权限就自动降级为纯计时模式，30 分钟照样提醒。
